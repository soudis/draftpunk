# The baseline is split between the generator and the starter design

What can be done mechanically is done by the generator on every page, so no edit by the agent can remove it: `loading="lazy"`, `decoding="async"` and the real `width` and `height` on pictures (the first picture of a page stays eager), `sitemap.xml`, `robots.txt`, a not-found page, font preload links, canonical and `hreflang` tags, and description and Open Graph tags from the page title and lede. What is visual lives in the starter design files and may be tuned by the agent: the font tokens and `fonts.yml` (which the generator turns into `@font-face` rules with `font-display: swap`), a CSS page transition (`@view-transition`, a short fade that is off for reduced motion, with no script and no library), a calm color behind a picture while it loads, a skip link, visible focus, and a menu that works on a phone with no script.

Fonts are files in the site, served from it. The starter ships Source Sans 3 and Source Serif 4. Another open-licence family is added with a tool that downloads it once on the server, so the visitor never contacts anyone else (ADR 0015). A blurred picture placeholder, a fade-in of pictures (a CSS animation ends before a lazy picture arrives), and a script-based page router were left out: they add generation work or a library and a way to leave the page blank. The sitemap and canonical addresses need the published address. The deployment knows it (ADR 0004) and passes it as `SITE_URL`; `url` in `site.yml` overrides it; without either they are left out. Setup does not ask for it.
