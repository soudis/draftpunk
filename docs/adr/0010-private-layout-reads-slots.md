# A private layout reads slots and holds no page content

A layout must not hold one page's sentences, picture addresses, or a rule that names that page. When a closed section shape can hold the content, the page uses a section list. When none can, that page may have a private template that reads slots written on the page in the same reply. A new section shape is still a change to this software. This revises ADR 0008's rejection of per-page templates: a private template is allowed only when no shape fits, and it still holds no content.
