# A habidat-setup module serves the editor and the public site on different hosts

The software is a multi-instance habidat-setup module, one instance per project, gated by one habidat group through OIDC. Visitors use the project's public domain. The editor and the private preview use a habidat subdomain. Booking, comments, search, public event submission, and the Direktkredit form are not part of this site. Publish stays off until the draft is bilingual and the public host is switched on.
